What this is
  Every file that changed when Today, Search, Projector mode, My progress, the Lesson builder,
  the new game modes, Record yourself, and the install/offline support were added.
  All 32 pages are here because each page carries its own scripts, so every page changed.

How to upload
  1. Open your repository on GitHub.
  2. Add file -> Upload files.
  3. Drag in EVERYTHING in this folder (38 files, one drag). GitHub replaces the old pages.
  4. Commit. Wait a minute, then open the site and press Ctrl+Shift+R (or Cmd+Shift+R) once.
